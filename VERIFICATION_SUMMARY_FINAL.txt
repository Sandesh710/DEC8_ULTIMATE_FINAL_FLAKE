2. ROOT CAUSE ANALYSIS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BUGGY CODE:
   C_TT_flk, C_Q_flk = C_TT_1 * C_T_p_flk - C_TT_2, 2.0 * C_TT_flk / C_T_p_flk
                                                            ^^^^^^^^
                                                       OLD VALUE (0.0)!

In Python tuple assignments, the ENTIRE right-hand side is evaluated BEFORE
any assignment occurs. This means:
   - First part:  C_TT_1 * C_T_p_flk - C_TT_2        → computes 0.15
   - Second part: 2.0 * C_TT_flk / C_T_p_flk         → uses OLD C_TT_flk = 0.0
   - Result:      C_TT_flk = 0.15, C_Q_flk = 0.0     → C_Q_flk is WRONG!

CORRECT (FORTRAN) EQUIVALENT:
   C_TT_flk = C_TT_1*C_T_p_flk-C_TT_2   ! Line 1: compute C_TT_flk first
   C_Q_flk = 2._ireals*C_TT_flk/C_T_p_flk  ! Line 2: use NEW C_TT_flk value

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. THE FIX
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CHANGED FROM (1 line):
   C_TT_flk, C_Q_flk = C_TT_1 * C_T_p_flk - C_TT_2, 2.0 * C_TT_flk / C_T_p_flk

CHANGED TO (2 lines):
   C_TT_flk = C_TT_1 * C_T_p_flk - C_TT_2
   C_Q_flk = 2.0 * C_TT_flk / C_T_p_flk

Now C_Q_flk correctly uses the NEWLY COMPUTED C_TT_flk value!

5. IMPACT ON PHYSICS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

C_Q_flk is used in the RADIATION FLUX TERM for bottom temperature:

   radiation_term = (I_intm_h_D_flk - (1.0 - C_Q_flk) * I_h_flk 
                    - C_Q_flk * I_bot_flk) * R_TI_icesnow / ...

With C_Q_flk = 0.0 (BUGGY):
   radiation_term = (I_intm_h_D_flk - I_h_flk) * R_TI_icesnow / ...
   ❌ MISSING RADIATION TERMS!

With C_Q_flk = 0.6 (FIXED):
   radiation_term = (I_intm_h_D_flk - 0.4*I_h_flk - 0.6*I_bot_flk) * ...
   ✅ CORRECT RADIATION PARTITIONING!

CASCADE OF ERRORS:
   1. Wrong C_Q_flk → Wrong radiation fluxes
   2. Wrong radiation → Wrong dT_bot/dt
   3. Wrong dT_bot/dt → Wrong T_bot evolution
   4. Wrong T_bot → Wrong temperature gradient (T_wML - T_bot)
   5. Wrong gradient → Wrong h_ML evolution
   6. Result: BOTH Tb and hML incorrect!
